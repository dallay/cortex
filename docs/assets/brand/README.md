## Cortex brand library

The [shared brand foundations](./brand-foundations.md) are maintained at this level. They cover the family palette, Geist Sans and Geist Mono, product typography, terminal fallbacks, and the review and export workflow. Keep brand-specific artwork and guidance with the corresponding product.

Each product uses the same delivery structure:

```text
<product>/
  <product>-identity.af
  brand-guidelines.md
  exports/
    assets/      reusable marks and icons
    artboards/   presentation sheets and studies
```

The three kits use the same inventory: 13 asset types and 17 presentation sheets, each in SVG and PNG. Use the files in `exports/` for integrations once the corresponding identity has been reviewed. See the guides for current artwork, variants and review status.
