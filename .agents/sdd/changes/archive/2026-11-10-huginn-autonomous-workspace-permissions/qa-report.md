## Ámbito no probado

- Ámbito no probado: otras versiones de macOS; disponibilidad/comportamiento futuro de interfaces de Seatbelt obsoletas; ejecución remota de CI; resistencia amplia a TOCTOU/condiciones de carrera más allá de las pruebas de rutas indicadas; aislamiento de herramientas nativas y MCP; fallo arbitrario de unlink del sistema operativo en el flujo completo del launcher.
- Motivo y relevancia: solo se observó macOS 27.3/build 26C5035r y no se ejecutó CI remoto. No existe una matriz fija de versiones macOS declarada (tarea 3.5); la tarea 3.6 establece un job PR-blocking y la validación local de su configuración/tests, no una corrida remota como precondición de aceptación. Estas son limitaciones visibles, no escenarios de aceptación pendientes del alcance actual. El aislamiento que no sea de shell y la paridad Linux/Windows están explícitamente fuera de alcance; la propuesta/spec/tasks no los establecen como pruebas requeridas. El contrato de limpieza aprobado no exige que unlink tenga éxito ante un fallo del sistema operativo ni exige un error de `File::close` no observable mediante la API segura.
- Requisito para repetir: no hay requisito de repetición para aceptar el alcance actual. La observación de versiones adicionales de macOS o de una ejecución remota puede añadirse a seguimiento futuro si se decide obtener esa evidencia; no se declara que ya se haya ejecutado. No hay repetición prevista para Linux/Windows parity ni para herramientas nativas/MCP, que son no goals.
